本周核心判断

AI 行业的竞争重心正在从“谁拥有更强模型”转向“谁能以更低成本、更可靠地交付工作结果”。本周，千问办公、WorkBuddy、豆包等产品加速汇聚办公入口；Muse Code 将模型与工具链同步优化；SeedRealtime 推动实时多模态交互；Gemini 团队调整与前沿基础设施加码则提示，人才和算力已成为长期供给能力的底层变量。

办公 Agent 任务交付 成本与价格 原生多模态 人才与算力

行业正在发生什么

  • 千问办公、WorkBuddy、豆包等办公产品线向统一入口收束，竞争开始围绕企业工作流和组织部署展开。
  • Muse Code 等编程 Agent 不再只是调用模型的外层工具，而是转向模型、终端、工具调用与验证机制的一体化设计。
  • SeedRealtime 代表的音视频能力，正从串联式拼接升级为同步感知、理解和表达的实时交互。
  • Gemini 团队调整与前沿厂商的基础设施投入表明，核心人才稳定性、算力供给和自主能力正在影响产品节奏。

为什么会这样发展

  • 通用对话和内容生成趋于普及，难以单独构成持续差异化。
  • 企业客户开始以真实任务完成率、交付时长、成本和可审计性判断 AI 的价值。
  • 长时程任务需要模型、工具、反馈与验证联动，产品体验不能只靠单次回答质量。
  • 模型训练与推理规模持续扩大，人才和算力直接影响产品迭代速度与服务稳定性。

四个生态信号

01 千问办公、WorkBuddy、豆包：办公入口集中化

多个产品在两周内完成组织或产品线整合：千问办公将 QoderWork、MuleRun 与悟空整合为企业级产品；QClaw 并入 WorkBuddy 所在部门；飞书团队并入豆包。海外的 ChatGPT Work、Claude Cowork 也在同步推进企业办公 Agent。

解决的问题：员工需要在多个工具间反复切换，任务上下文分散，难以让 AI 获取完整工作信息。

AI 技术与产品形态：桌面端、云端与企业协同端融合，Agent 可拆解任务、调用工具、并行执行并交付可编辑文件、数据报告或网页。

产生的价值：统一入口降低使用门槛，让岗位任务能够被连续理解、执行和沉淀为可复用流程。17 款桌面端产品的月访问量在四个月内由 2,000 万增至 6,000 万，验证了办公 Agent 的规模化需求。

02 Muse Code：编程 Agent 进入系统战

Muse Code 以完整产品形态进入编程 Agent 赛道，直接对标 Claude Code 与 Codex。产品竞争不再只看模型跑分，而是看模型、终端、工具调用、验证机制与价格策略的整体配合。

解决的问题：复杂开发工作难以仅靠单次代码生成完成，过程中的上下文理解、执行和验证仍高度依赖人工。

AI 技术与产品形态：模型与 harness 协同训练；持久化异步后台 Agent；多 Agent 在独立 worktree 并行执行；本地日志支持调用重放、崩溃恢复与全程审计。

产生的价值：将需求拆解、编码、测试与修复串成可验证的交付链路，缩短业务需求转化为应用能力的周期。低价策略也在推动编程 Agent 从高价工具走向规模化使用。

03 SeedRealtime：多模态交互迈向实时原生

SeedRealtime 已在豆包 App 中展示实时音视频通话体验。与传统的“语音识别→视觉理解→文本推理→语音合成”级联方案相比，它以统一模型完成连续多模态感知、理解、决策和表达。

解决的问题：级联式交互容易产生延迟、信息损失和打断感，难以承接需要看、听、说同步进行的复杂协作。

AI 技术与产品形态：音视频联合理解、主动环境感知与自然节奏把握，支持基于手势、视线和语气的实时交互。

产生的价值：降低复杂任务的表达成本，使指导、审核、培训和现场辅助等场景获得更自然、更及时的人机协作体验。实时全双工能力会逐步成为 AI 助手体验的基础门槛。

04 Gemini 与前沿基础设施：人才与算力成为长期变量

Gemini 团队的组织调整、核心研究人员流动，以及前沿厂商在云计算、芯片和数据中心上的重投入共同表明，模型竞争已延展到人才密度与基础设施自主能力。

解决的问题：企业部署 AI 时会面临模型迭代不确定、服务成本波动和长期供给能力不足的风险。

AI 技术与产品形态：竞争从通用模型能力，延展到芯片、数据中心、云计算协议和模型安全治理等全栈能力。

产生的价值：将生态伙伴的稳定供给能力纳入评估，帮助平台选择具备长期迭代、成本控制与服务保障能力的合作对象，也提示组织要将安全治理纳入采购与部署的前置条件。

平台建设行动启示

从功能看交付

生态伙伴评估不能只看模型能力或功能清单，应增加任务完成率、人工介入次数和结果可复核性等指标。

从入口看连接

优先关注能进入文档、项目、数据、消息和流程系统的能力，连接深度决定后续的岗位价值。

从试用看治理

当 Agent 开始执行操作，权限、审批、日志和人工确认应成为产品的默认能力，而不是后置补丁。

从通用看场景

围绕合同、招投标、文档审核、数据分析和内容制作等高价值流程沉淀可复用模板。

从交互看效率

多模态实时交互有望降低复杂任务的表达成本，但应优先选择可量化收益的应用场景。

从产品看供给

持续观察生态伙伴的核心团队、算力策略、价格稳定性和开放连接能力，判断合作的长期确定性。

核心观点提炼

AI Agent 的下一阶段，不是增加更多孤立功能，而是将模型、工具、流程与组织治理连接起来，稳定交付一项真实工作结果。

AI 办公产品的竞争将不再局限于“回答得像不像人”，而在于“任务能否完成、过程能否控制、结果能否复用”。

后续关注点

  • 统一办公入口能否带来持续活跃、任务完成率提升和企业级付费转化。
  • 编程 Agent 的价格竞争、可审计能力与多 Agent 协作是否改变企业采购与开发工具格局。
  • 原生实时多模态能力是否开放给第三方，从体验差异变为可集成的生态能力。
  • 前沿团队的人才流动、基础设施投入与开源模型安全治理，是否继续影响伙伴稳定性。
