04 / 系统能力

技术架构：身份、记忆与推理协同

层级主要工作验收重点
身份与权限绑定用户 / 企业 / 设备，接入业务工具身份误关联、最小权限、撤权
记忆与资料保存历史，检索并更新事实来源、过期信息、删除传播
模型与语音专用小模型，ASR → 推理 → TTS任务正确率、响应尾延迟
部署与执行边缘或云端推理，调用业务系统成本、隔离、恢复、最终业务状态

公开技术组合包含蒸馏、LoRA、RAG 与 CAG；记忆需要系统治理。

09 / CPU 与基础设施

01

模型推理

语音模型测试使用 GPU；需测 ASR、推理和 TTS 的实际承载资源。

02

工具执行

测 API 服务、浏览器、脚本、文件处理和检索的 CPU 与内存。

03

持续状态

单独统计记忆存储、等待、休眠、唤醒、日志和审批成本。
